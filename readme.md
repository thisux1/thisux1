## About me

I'm Thiago. I build things mostly because I want to understand how they work.

Most projects start with a *"what if?"* and escalate from there. A web app turns into a payment system. A document parser turns into an asynchronous AI pipeline. A glove ends up flying a drone.

I like working on the boundaries between things: product and engineering, software and hardware, deterministic systems and AI. That usually means following a problem all the way down: architecture, data, APIs, interfaces, infrastructure, failure modes, and whatever else gets in the way.

I'm especially interested in agents, automation, intelligent systems, and tools that make complicated machinery feel simple.

Outside software, it's usually physics, cosmology, psychology, philosophy, photography and music.

> Mostly, I like making ideas real.
